# Preorder, customer service, franchise and stock SOP

1. Product marked preorder only after approved sample, actual supplier capability and price/cancellation terms. Display anticipated ship date **window** and evidence basis. Each paid order snapshots expected ship date, legal terms and variant.
2. Capture payment after validated gateway event. Issue order confirmation and relevant receipt; tax-invoice timing reviewed by CA. Reserve **production capacity**, not fictional physical stock. Order joins a constrained batch by garment, size, material, printer and supplier.
3. Batch order supplier confirmation -> printing/cutting -> sewing/finishing if relevant -> print QC + wash-test benchmark -> pack quality -> label/AWB -> courier -> tracking.
4. Delay exception: escalation to supplier, revised timeline, notify affected customers, easy support/cancellation where legally required. Don't use force majeure boilerplate to hide routine delays.
5. Refunds: audit reason, original payment refund and webhook reconciled, update stock/capacity, credit note per tax advice; exchanges handled with restocking ledger after physical receipt.
6. Store stock physical ledger by store; online design concepts never appear as available in POS; franchise-owned vs centrally-owned stock separate; shift reconciliation and cashier trail.
7. Returns: request -> eligibility review -> reverse pickup -> QC -> approve/refund/credit note; defect and incorrect-item rights respected irrespective of discretionary policy windows.
8. KPIs: production on-time %, first-contact resolution, avg payout delay, delivered vs ETA, INR contribution after returns, refund backlog, inventory shrinkage, repeat and COD issues (COD off by default).
