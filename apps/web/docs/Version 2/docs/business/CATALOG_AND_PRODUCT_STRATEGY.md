# Catalog and launch assortment

## Categories
**Tees:** oversized heavyweight 220–260 GSM (if vendor-verified), standard relaxed 180–220 GSM, workout breathable fabric (actual composition, print compatibility, care instructions validated). **Bottoms:** relaxed joggers, taper track pants, straight fit, performance pants; leg art placement and abrasion/stretch constraints apply. **Collections:** Unsaid / No Fake Friends / Offline Mind / Motion > Motivation / Campus Chaos / Night Shift / After Hours / Desi Philosophy / Quiet Rebel / Gym Ritual / Seasonal Drops. Each launch product starts from a standard certified garment blank, not AI-designed physics-defying seams.

## SKU dimensions
Product style is one print+garment spec; variants are fit, size, color, fabric; SKU stable: `VM-{CAT}-{DESIGN}-{FIT}-{COLOR}-{SIZE}`. Material consumption/fulfilment estimates are vendor-based. `StockOnHand=0` by default, with separate `preorderCapacity`, `unitsReserved`, `supplierConfirmedUnits`; never misrepresent theoretical capacity as actual inventory. Customer options shown only if size and supplier matrices validated.

## Catalog fields required
Gender presentation (women/men/unisex) as navigation convenience, not fit guarantee; age of models 18+; base garment, GSM, composition, weave, actual measurements and model size; care, print method, ethical sourcing statement only if verified, seller & origin, HSN, MRP/offer price/30-day low, discount code, SKU, made-to-order indicator, dispatch window and cancellation policy.

## Caps and gates
Max concept generation 100 per job; max 30 live SKUs at launch; manual admin approval per product; print test upload; sampled product photos replace AI marketing renders before expanded rollout. Every unverified quote flagged and invisible publicly. Discounts require margin threshold.
