# Senior apparel designer's production specification

## Differentiation by garment use
**Daily tees:** breathable fabric, durable relaxed construction, print placement that remains legible during movement, realistic color-on-fabric contrast. **Gym tees:** moisture, stretch, wash-frequency performance, print heat/breathability, abrasion resistance and performance-labelling accuracy. **Track pants:** panel/seam-aware graphics, text orientation, squat/knee stretch and print fatigue, pocket/waist/drawcord location, hem accessibility. Print art on pants should not just be scaled-down T-shirt graphics.

## Factory tech-pack fields required
Brand style ID, revision, fit classification, actual base pattern, gender fit optional, category, supplier code, exact fabric and color reference, weights (GSM measured, not promised), construction and stitch type, grading table, measurement points and tolerance, print/surface method, placement from nearest reference seam, artwork printable bounding box (mm), ink/pigment/color references, min line thickness, neck/waist label, care label, country-of-origin, packaging, unit COGS by size, test photos, approval sign-off and version history.

## Proposed *starting* size range, not measurements
XS, S, M, L, XL, XXL for tees and pants. Do not invent chest/waist/inseam values. Vendor must supply graded measurements per garment style; sizes vary by pattern and fabric. Consider plus sizes after supplier fit review, no exclusion by gender/age. Model imagery for adults 18+ only with consent and truthful representation.

## Print quality test plan
- Legibility at 1m, 30cm, 20% thumbnail, on light/dark fabric; Unicode fonts covered by valid commercial license.
- 10-cycle wash test or vendor agreed applicable standard, shrink %, print cracking, pilling and fading, color transfer and crocking, seam tensile and elasticity where relevant; document actual measurements.
- Print file: editable source SVG/PDF, actual dimensions mm, raster at printer-approved PPI when required, agreed transparent background/bleed/separation, safe margins from seams, independent layer for text. RGB mockup only = not production-approved.
- Proof rounds: in-house designer -> apparel senior -> supplier -> QA -> merchandising. Hash every approved asset; supplier print uses exact approved revision.
- Track pants typography can run down outer seam, thigh or at ankle; verify no print obscured by pockets or seams.
- Avoid skin-tone changes, body manipulation, faked drape, falsely represented garment fabric in generated marketing model imagery.

## Weekly brand capsule brief examples
1. `FRENEMY? / HONEST FRIEND`: type-focused oversized tee, black + bone, accessible print size, phrase original and reviewed.
2. `STATIC / NOISE`: minimal left-chest tee, larger back print, no generic AI swirls.
3. `AFTER CLASS`: humour-led campus tee, light fabric, visual wordplay not infringing university logos.
4. `MOTION > MOTIVATION`: jogger with seam-aligned motivational side panel that survives wash/stretch.
5. `RESET`: track pant with one-line ankle print paired with a plain tee, street-to-gym wear.

Only physical samples with sign-off can be converted from designs to preorder products.
