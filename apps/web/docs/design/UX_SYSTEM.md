# UX product system — premium, witty, fast, no copycat design

**Visual:** oversized confident grotesk typography, near-black `#111318`, bone `#F4F0E8`, acid-lime `#C7F45D` only as tiny CTA accents, muted lilac and rust capsule labels, subtle grain behind editorial photography, no excessive skeuomorphism. Mobile-first >=360 px; accessible WCAG 2.2 AA. High contrast text, reduced motion, keyboard nav, visible focus, 44px touch targets. Adult models with consent. Each product is unmistakably marked PREORDER and realistically explained.

**Navigation:** Shop / Tees / Track Pants / Drops / Philosophy / How Preorders Work / Cart; search, favorites, profile. Gender category as optional filter only. Trust footer: company details, contact/grievance, returns, shipping, invoices, privacy, terms.

**Home modules:** opening hero, trending drops based on real metrics (not fake), motto editor, collections, real preorder explanation, how to find fit, honest customer UGC only if permission and verifiable, design-vote section. Movement and quiet philosophy collections.

**PDP:** 6+ responsive images (real garment photos preferred); colors; size picker; exact garment measurements; fabric/care; placement map; estimated ship range and current preorder stage; total price/tax/shipping disclosed before payment; seller/origin; cancellation; inclusive fit examples. For renders use "Illustrative mockup; actual colour/fit may vary" until verified.

**Cart/Checkout:** guest browse, Google sign-in or appropriate allowed guest checkout decision, address/pincode, verified totals, consent for legal terms and separately for promotional WhatsApp/SMS/email; a confirmation summary states *This is a preorder, not an in-stock item*. Paid orders require gateway capture evidence.

**Customer account:** Google login -> orders -> stage timeline (paid / vendor confirmed / cutting / printing / QC / shipped) -> AWB and receipts -> request cancellation / return -> support ticket; dob optional for 18+ birthday discount, no age inference or forced birthdays.

**Admin:** sidebar Today, Design Studio, Approvals, Catalog, Preorder Batches, Orders, Payments, Shipping, Returns, Promotions, Customers, Communications, Supplier, Stores/POS, Reports, Settings/Integrations, Security/Audit. Alerts on aged unfulfilled orders, low margin, failed payment webhooks, invalid tax config. Every destructive operation confirm + audit.

**Onboarding:** four-step founder setup: Identity & legal -> Production supplier -> Payment & shipping -> Communication & policy -> launch health. Never ask merchant to paste credentials into public-facing forms.

**Franchise POS:** barcode/sku lookup, stock physically available by location, employee roles, tax invoice, cash/UPI/card tender methods (payment device integration), offline queue constraints, returns and customer receipts, commission. Clearly distinguish ship-to-store preorder from retail-stock cash-and-carry.

**No dark patterns:** no deceptive countdowns, auto-added products, disguised sponsored slots, fake 5-star reviews, disabled unsubscribe, coerced consent or hidden discounts.
